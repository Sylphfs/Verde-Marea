# design.md — визуальная система Verde Marea

## Палитра

| Токен | Hex | Назначение |
|-------|-----|------------|
| forest (тёмно-зелёный) | #1F4D3A | Основной цвет, кнопки, заголовки, бренд |
| gold (золото) | #C7A76C | Акцент, выделение, hover-состояния |
| cream (крем) | #F5F1E8 | Фон страниц и карточек |
| ink (почти чёрный) | #1B1B1B | Основной текст |

Семантические статусные цвета (используются только в бейджах статусов):
- pending — золото #C7A76C
- confirmed — зелёный (forest-спектр)
- cancelled — нейтральный серый
- completed — тёмно-зелёный (forest)
- no_show — приглушённый красный (danger, только для этого статуса)

## Шрифты

| Роль | Шрифт |
|------|-------|
| Заголовки | Cormorant Garamond (serif) |
| Текст | Manrope (sans) |

## Токены

- Скругления: карточки/кнопки — 8px (rounded-lg), бейджи — 999px (rounded-full).
- Отступы: базовая сетка 4px; секции — 24–48px.
- Тени: мягкая, низкая прозрачность чёрного; для карточек — лёгкая.
- Типографика: заголовки крупные и лёгкие (serif), основной текст 14–16px (sans), line-height 1.5.

## Правила компонентов

- Кнопки: primary — forest-фон + cream-текст; secondary — прозрачный/крем фон + forest-рамка; акцент — gold. Hover — затемнение/подсветка; состояние disabled — приглушённое.
- Ссылки и интерактив — с focus-visible состоянием.
- Единый отступ и скругления во всех компонентах (из токенов).

## Форма

- Каждое поле: label + input + текст ошибки.
- Ошибка валидации — красный текст под полем, поле подсвечивается.
- Валидация на сервере через Zod; UI отображает ошибки сервера.
- Обязательные поля помечаются.
- Кнопка отправки — с состоянием загрузки (disabled + текст «…»).

## Карточка

- Фон cream (или белый на cream-фоне), лёгкая тень, скругление 8px.
- Заголовок — serif, основной текст — sans.
- Используется для: слота бронирования, брони в списке, сводки.
- В карточке брони обязательно виден статус (бейдж).

## Таблица / список

- Админка использует таблицу (десктоп) и список (мобильный).
- Шапка таблицы — единый стиль (forest-фон с cream-текстом).
- Строки — с hover-подсветкой; колонки статусов — бейджи.

## Бейджи статусов

| Статус | Вид |
|--------|-----|
| pending | золотой бейдж, тёмный текст |
| confirmed | зелёный бейдж, cream/белый текст |
| cancelled | серый бейдж |
| completed | тёмно-зелёный бейдж |
| no_show | приглушённо-красный бейдж |

Форма — rounded-full, компактный размер, текст 12px.

## Уведомление

- Служебные уведомления — внутри приложения (toast/список), без внешних провайдеров.
- Виды: успех (зелёный), ошибка (красный), информация (нейтральный/золотой).
- Показываются кратко, с возможностью закрыть; в списке — тип + текст + время.
