# План реализации Verde Marea

Работа ведётся строго по этапам. Номер и содержание этапа задаёт автор проекта командой «Этап N. …»; этот файл фиксирует общую дорожную карту по слоям.

## Дорожная карта по слоям

### База данных
- `prisma/schema.prisma`: модели User, Table, Slot, Booking, Notification, AuditLog; enum ролей и статусов.
- Миграции через Prisma Migrate.
- Seed: начальные столы, супер-админ, генерация слотов на 14 дней.

### Бэкенд (серверная логика)
- Аутентификация: регистрация, вход, хэширование пароля bcryptjs (12 раундов), защита маршрутов по ролям.
- Бронирование: расчёт и проверка окон (14 дней, вт–вс, шаг 90 мин, 12:00–21:00, без прошедших и занятых окон, наличие подходящего стола).
- Отмена: правило «не позднее 3 часов до начала» — на сервере.
- Администрирование: смена статусов, ролей.
- AuditLog и Notification: запись событий и уведомления.
- Все критические проверки — только на сервере; входные данные валидируются через Zod.

### Фронтенд
- Страницы: вход/регистрация, выбор окна и бронирование, «Мои брони», админ-панель (брони, пользователи, журнал).
- UI-компоненты по design.md: формы, карточки, таблицы/списки, бейджи статусов, уведомления.
- Tailwind-токены из design.md; шрифты Cormorant Garamond и Manrope.

## Предварительный порядок этапов
(уточняется автором на каждом шаге)

1. Документация и рамки проекта.
2. Инициализация Next.js + Tailwind + Prisma, базовые настройки.
3. Схема БД, миграция, seed.
4. Аутентификация.
5. Бронирование и проверка окон.
6. Админ-панель и статусы.
7. Уведомления и аудит.
8. Финальная полировка UI и проверка по чек-листам.
